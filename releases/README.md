# Hasil build

`naqdi-kasir-debug.apk` — APK **debug** aplikasi kasir Android (dibangun 2026-10-16 dari commit sebelum berkas ini). Hanya untuk uji di tablet sendiri: ditandatangani kunci debug, bukan untuk Google Play. Alamat server tertanam: `https://naqdi.excoder.site`. Cara membangun ulang dan mengubah alamat: docs/08-mobile.md.

Berkas biner di Git tidak bisa dihapus dari riwayat tanpa menulis ulang riwayat; jangan menambah APK baru tiap build. Untuk rilis, simpan AAB/APK bertanda tangan di GitHub Releases atau Play Console, bukan di repositori.
